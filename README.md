
# Expense Tracker 2.0

## MainCrafts Python Programming Internship - Task 3

### Project Description
An improved command-line Expense Tracker developed
using Python and CSV file handling.

### Features
- Add expenses with categories.
- View all expenses.
- Search expenses by category.
- Calculate category-wise spending.
- Calculate monthly spending.

### Technologies Used
- Python
- CSV Module
- VS Code

### How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Execute:

   python3 task3.py

### Storage
All expenses are stored in expenses.csv.
